### REMIX GAUNTLET: MUTANT LAB & HEIST VAULT
*A 4-Player Asynchronous Challenge Exchange*

One player creates the trap. The next player must survive it.

Remix Gauntlet is a high-suspense competitive game where level design IS the battlefield:
- 🧪 MUTANT LAB ESCAPE: Assemble hazardous collapsing platforms, chemical spikes,
  centrifuge blades, and acid basins, then race against the clock to make a clean break.
- 💎 HEIST REMIX: Plot the vault layout, program patrol sentries, aim security cameras,
  and conceal the target diamond before infiltrating rival blueprints.
- ⚡ NEURAL SYNDICATE: Lay high-value data bait across neon alleyways, rig neural
  stasis traps, and test whether rival couriers will choose survival or pure greed.

Features:
• Circular 4-Player Handover (P1 → P2 → P3 → P4 → P1)
• Step-by-Step Drag-and-Drop Hurdle Placement with Orientation & Velocity Tuning
• 100-Point Strategic Difficulty Budget (Easy 25% → Extreme 100% Beatable)
• Dynamic 4-Second Non-Lethal Trap Lockdowns
• Fog-of-War Curiosity Horizon & Post-Game Intel Reveal
• Local 4-Player Pass & Play or Solo Mode against Adaptive AI Architects
